# NovaCare System Care Suite 2026 ⚡

**NovaCare System Care Suite**, *CCleaner*, *Glary Utilities* ve *IObit Advanced SystemCare* benzeri, Windows sisteminizi derinlemesine optimize eden, gereksiz dosyaları temizleyen, RAM kullanımını azaltan ve kayıt defteri hatalarını güvenle onaran profesyonel bir sistem bakım ve optimizasyon yazılımıdır.

## 🌟 Öne Çıkan Modüller ve Özellikler

### 1. 🚀 Tek Tıkla Bakım (1-Click Maintenance)
* **Sağlık Skoru Göstergesi:** 0-100 arasında bilgisayarınızın genel sağlık durumunu anlık olarak analiz eden dinamik dairesel gösterge.
* **Tek Tıkla Tarama & Onarım:** Gereksiz dosyalar, bozuk kayıt defteri anahtarları, gizlilik izleri ve başlangıç programları aynı anda taranır ve tek tıkla onarılır.
* **Canlı Sistem Metrikleri:** CPU yükü ve RAM kullanımı anlık olarak izlenir.

### 2. 🧹 Gereksiz Dosya ve Önbellek Temizleyici (Junk Cleaner)
* **Kullanıcı ve Sistem Temp:** `%TEMP%` ve `C:\Windows\Temp` dizinlerindeki geçici dosyaları temizler.
* **Geri Dönüşüm Kutusu:** Windows Geri Dönüşüm Kutusunu sessizce ve güvenle boşaltır.
* **Windows Update İndirme Önbelleği:** Güncellemelerden sonra diskte kalan eski kurulum paketlerini temizler.
* **Çökme ve Hata Raporları:** Minidump ve WER hata günlüklerini temizler.
* **Küçük Resim Önbellekleri (Thumbnails):** Bozulmuş veya şişmiş `thumbcache_*.db` dosyalarını temizler.
* **Web Tarayıcıları:** Google Chrome, Microsoft Edge, Brave ve Mozilla Firefox tarayıcılarının önbellek, kod ve GPU önbelleklerini temizler.
* **Geliştirici ve Uygulama Önbellekleri:** Discord, Spotify, pip ve npm önbelleklerini temizler.

### 3. 🛠️ Kayıt Defteri Temizleyici ve Onarıcı (Registry Cleaner)
* **Güvenli Tarama:** Geçersiz başlangıç girdileri, silinmiş program kalıntıları, kayıp paylaşılan DLL'ler ve bozuk MUI Cache kayıtlarını denetler.
* **Otomatik Geri Alma Yedeği:** Her onarım işleminden önce otomatik olarak hem `.json` hem de yerel Windows `.reg` dosyası oluşturur.

### 4. ⚡ Başlangıç Yöneticisi (Startup Optimizer)
* Windows açılışında başlayan programları (Kayıt defteri Run/RunOnce ve Başlangıç Klasörleri) listeler.
* **Açılış Etkisi Puanlaması:** Programların sistem açılışına etkisini *Yüksek*, *Orta* veya *Düşük* olarak değerlendirir.
* **Aç / Kapat (Toggle):** Girişleri silmeden geçici olarak devre dışı bırakabilme veya kalıcı olarak silebilme.

### 5. 📦 Program ve Artık Dosya Kaldırıcı (App Uninstaller & Leftover Cleaner)
* Yüklü 32-bit ve 64-bit tüm yazılımları listeler (Boyut, sürüm, yükleme tarihi).
* **Resmi Kaldırıcıyı Başlatma:** Programın kendi kaldırıcı aracını çalıştırır.
* **Derin Artık Temizliği (Leftover Cleaner):** Kaldırılan programların Program Files, AppData ve Kayıt Defteri'nde unuttuğu kalıntıları bulur ve tek tıkla temizler.

### 6. 🧠 Bellek (RAM) Hızlandırıcı ve Süreç Yöneticisi (RAM Booster)
* **Canlı Bellek & CPU Grafikleri:** Anlık kullanım oranlarını gösterir.
* **RAM'i Hızlandır & Boşalt:** Windows `EmptyWorkingSet` API'si aracılığıyla arka plandaki tüm süreçlerin gereksiz çalışma kümelerini boşaltıp gigabaytlarca RAM'i anında geri kazandırır.
* **Süreç Yöneticisi:** Çalışan işlemleri PID, bellek ve CPU kullanımına göre listeleyip sonlandırma imkanı tanır.

### 7. 📊 Disk Alanı ve Büyük Dosya Analizörü (Disk Analyzer)
* Sürücü doluluk oranlarını görselleştirir (C:, D:, vb.).
* Diski dolduran en büyük dosyaları (Video, Arşiv, ISO, Kurulum vb.) kategorilerine göre anında listeler ve dosya konumunu açma veya güvenle silme seçenekleri sunar.

### 8. 🛡️ Gizlilik Kalkanı ve Windows Optimizasyonu (Privacy Shield & Tweaks)
* **Etkinlik İzleri:** Son açılan dosyalar, Çalıştır (Win+R) geçmişi, Dosya Gezgini adres geçmişi ve Pano belleğini temizler.
* **Windows 10/11 İyileştirmeleri:** Telemetri ve tanılama verisi toplama, reklam kimliği, etkinlik geçmişi, Başlat menüsü Bing aramaları ve Game DVR'ı tek tıkla kapatabilme.

### 9. 💾 Kurtarma ve Yedekleme Merkezi (Rescue Center)
* Temizlik işlemlerinde alınan kayıt defteri yedeklerini listeler ve tek tıkla geri yükler.
* Windows Sistem Geri Yükleme Noktası (System Restore Point) oluşturma ve Windows kurtarma sihirbazını başlatma desteği sunar.

### 10. 🔄 GitHub Otomatik ve Manuel Güncelleme Sistemi (Updater)
* **Manuel Güncelleştirme:** "Ayarlar & Güncelleme" sekmesinden veya komut satırından tek tıkla GitHub Releases API'sini denetleme.
* **Otomatik Güncelleştirme (Açılışta):** Program başlatıldığında arka planda sessizce GitHub'ı sorgular, yeni sürüm tespit edilirse bildirim rozeti ve güncelleme onay penceresi gösterir.
* **Tek Tıkla Kurulum & Yeniden Başlatma:** Yeni sürüm paketini indirir, arka planda güvenle günceller ve uygulamayı otomatik olarak yeniden başlatır.
* **Özelleştirilebilir GitHub Deposu:** Ayarlar sekmesinden istenilen GitHub repo adı (`kullanıcı/depo`) kolayca yapılandırılabilir.

## 🚀 Çalıştırma Talimatları

### Grafik Arayüzü (GUI) ile Başlatma:
Doğrudan `Başlat_NovaCare.bat` dosyasına çift tıklayabilir veya komut satırından çalıştırabilirsiniz:
```powershell
python main.py
```
*(Arka planda konsolsuz başlatmak için: `pythonw main.py`)*

### Komut Satırı (CLI) Hızlı Kullanım Seçenekleri:
Arayüzü açmadan doğrudan komut satırından işlem yapmak için:
* **Hızlı RAM Temizleme:**
  ```powershell
  python main.py --boost-ram
  ```
* **Hızlı Gereksiz Dosya Taraması:**
  ```powershell
  python main.py --quick-scan
  ```
* **GitHub Güncelleştirmelerini Denetleme:**
  ```powershell
  python main.py --check-update
  ```

* **İşletim Sistemi:** Windows 10 veya Windows 11 (64-bit)
